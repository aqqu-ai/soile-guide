# SOILE Platform Components

The SOILE platform combines an offline-first tourist application with optional edge intelligence infrastructure deployed in remote regions.

The system is designed for environments with limited connectivity, allowing tourists to access navigation, information, and safety services without relying on continuous internet access.

---

## Tourist Layer

The tourist layer consists of the Progressive Web Application (PWA) installed on mobile devices.

Capabilities:

• offline route navigation  
• downloadable route packages  
• local map rendering  
• multilingual tourism content  
• safety notifications  
• low power mobile operation  

The PWA works entirely offline once route packages are downloaded.

---

## Edge Intelligence Layer

Optional edge nodes deployed along tourism routes provide localized intelligence and environmental monitoring.

Capabilities:

• environmental monitoring  
• safety event detection  
• local vision pipelines  
• local reasoning for alerts  
• data synchronization with tourist devices  

Edge nodes operate autonomously and synchronize data when connectivity becomes available.

---

## Regional Infrastructure Layer

Regional infrastructure integrates multiple tourism services and edge nodes.

Functions:

• route management  
• safety coordination  
• tourism analytics  
• emergency response support  
• optional cloud synchronization  

This layer is typically operated by government tourism organizations or regional authorities.

---

## Platform Design Principles

SOILE is built around several key principles:

• offline-first operation  
• minimal infrastructure requirements  
• sovereign data control  
• optional edge intelligence  
• compatibility with GOVTECH tourism systems
